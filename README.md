# JinSimLauncher

在 Android 上运行 Minecraft Java 版的启动器，带自有账号体系。

## 下载

最新版本在 [Releases](https://github.com/JinSimTech-China/JinSimLauncher/releases) 页面；国内访问慢可以用 gh-proxy 加速（直链前面加 `https://gh-proxy.org/`）。

系统要求：Android 8.0 及以上，单 APK 直接安装。

## 这是什么

- 内置 JinSim 账号体系：离线、微软正版、第三方皮肤站统一成一个云端 ID，换设备登录自动拉回
- 手机触控布局开箱可用，不用另外装按键配置
- 插物理鼠标键盘会自动隐藏虚拟按键、隐藏系统指针
- 更新走自家通道，不混上游版本
